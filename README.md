# AerofoilX ✈️
### Airfoil Design & Aerodynamic Analysis Platform

AerofoilX is a Python-based aerospace engineering project for generating NACA airfoils, analysing aerodynamic performance and comparing different airfoil profiles using XFOIL.

## Features
- NACA 4-digit airfoil generation.
- Reynolds number and dynamic pressure calculation.
- XFOIL aerodynamic analysis.
- Lift and drag performance graphs.
- Pressure coefficient (Cp) distribution.
- Multi-airfoil comparison.
- Estimated stall analysis.
- CSV data export.

## Tech Stack
- Python
- Streamlit
- XFOIL
- NumPy
- Pandas
- Plotly
- Matplotlib

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/AerofoilX.git
cd AerofoilX
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Install and configure XFOIL for your operating system.

Run the application:

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## Project Objective

To combine aerospace engineering concepts with Python programming and provide an interactive platform for airfoil design and aerodynamic performance analysis.
